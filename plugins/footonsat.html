FootOnSat — مواعيد وتفاصيل المباريات

متابعة جدول المباريات والنتائج وحالة اللقاءات من واجهة الرسيفر.

📌 وظيفة البلجن

FootOnSat إضافة لأجهزة Enigma2 تعرض مواعيد المباريات والنتائج وحالة اللقاء، مع شعارات الفرق والمسابقات. المعلومات التالية مستخلصة من مستودع المطوّر وملفات المشروع، وقد تختلف التفاصيل حسب الإصدار ومصدر البيانات المستخدم.

⭐ أبرز المميزات المذكورة في المشروع

  • عرض مباريات اليوم والغد، ومراجعة مباريات الأمس والمباريات المنتهية.
  • إظهار النتيجة وحالة المباراة، مثل وقت اللعب أو نهاية المباراة، عند توفر البيانات.
  • عرض شعارات الفرق وأعلامها وبعض معلومات البطولة.
  • أقسام للترتيب في البطولات التي يدعمها مصدر البيانات.
  • إشعارات وخيارات مرتبطة بالقنوات، مع إمكانية فحص القنوات وفق وصف المشروع.
  • إمكانية حفظ مباريات مفضلة، وتشغيل فيديوهات ملخصات للمباريات إذا كانت متاحة.
  • تظهر في الكود بطولات منها دوري أبطال أوروبا، الدوري الإنجليزي، الإسباني، الإيطالي، الألماني، السعودي، وبعض بطولات آسيا وكأس العالم، بالإضافة إلى أقسام رياضات أخرى.

تنبيه: وجود البطولة أو الميزة في الكود لا يضمن أن مصدر البيانات يعمل دائمًا أو أن كل المسابقات متاحة في كل وقت.

🖼️ صور حقيقية من مستودع المشروع

الصور التالية مضمّنة في README الخاص بالمشروع، وتعرض واجهة البلجن والتنبيهات.

⌨️ أمر التثبيت عبر Telnet / SSH

الأمر كما أرسلته:

wget https://raw.githubusercontent.com/fairbird/FootOnsat/main/Download/install.sh -O - | /bin/sh

مراجعة سكريبت التثبيت قبل التشغيل ↗

🛠️ طريقة التثبيت وملاحظات التوافق

  1. اتصل بالرسيفر عبر Telnet أو SSH.
  2. راجع سكريبت التثبيت من الرابط أعلاه قبل تشغيله، لأنه ينزّل كودًا من الإنترنت وينفذه بصلاحيات الجهاز.
  3. بعد التأكد من المصدر والتوافق مع صورة النظام، نفّذ الأمر في الطرفية.
  4. اتبع أي خيارات تظهر أثناء التثبيت؛ السكريبت قد يتيح اختيار التخزين الداخلي أو الخارجي بحسب إعداد الجهاز.
  5. أعد تشغيل واجهة Enigma2 إذا طلبت تعليمات المشروع ذلك، ثم ابحث عن FootOnSat في قائمة البلجن.

التوافق يعتمد على صورة Enigma2 وموديل الرسيفر والمكتبات المتوفرة. لم يتم اختبار التثبيت على جهاز فعلي هنا. بعض وظائف الفيديو قد تعتمد على إعدادات ومشغّل خارجي مناسب؛ راجع README والمناقشات الرسمية عند ظهور مشكلة.
