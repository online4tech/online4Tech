📡 بلجن عرض معلومات الإشارة لأجهزة Enigma2

RaedQuickSignal

عرض معلومات القناة والإشارة، مع دعم عرض وتنزيل صور القنوات (Picons).

📌 وظيفة البلجن

بحسب README الرسمي لمستودع المطوّر Fairbird، يعرض RaedQuickSignal معلومات عن القنوات، ومنها SNR وAGC وصورة القناة (Picon) ومعلومات التشفير، كما يتيح تنزيل صور القنوات.

المستودع الرسمي على GitHub ↗ · README الرسمي ↗

⭐ المميزات المؤكدة

  • عرض قيمة SNR الخاصة بالإشارة.
  • عرض معلومات AGC.
  • عرض Picons للقنوات.
  • إظهار معلومات القناة المشفرة.
  • تنزيل صور القنوات (Picons).

لم أضف وظائف إضافية غير مذكورة في README الرسمي.

⌨️ التثبيت عبر Telnet / SSH

الأوامر كما أرسلتها، مع الحفاظ على ترتيبها:

opkg update opkg install wget wget https://raw.githubusercontent.com/fairbird/RaedQuickSignal/main/installer.sh -O - | /bin/sh

السكريبت الرسمي يحدد الإصدار 19.0 في رأس الملف وقت المراجعة، ويتعامل مع بعض الاعتماديات ويحاول حفظ ملفات وإعدادات من التثبيت السابق.

⚠️ ملاحظات مهمة

  • تأكد من توافق صورة Enigma2 وإصدار Python مع جهازك قبل التثبيت.
  • السكريبت يحذف مجلد البلجن القديم قبل نسخ الملفات الجديدة، مع محاولة حفظ بعض الملفات ومجلدات Picons واستعادتها.
  • أمر التثبيت ينزّل سكريبتًا من الإنترنت وينفذه مباشرة؛ راجع محتوى السكريبت قبل التشغيل وخذ نسخة احتياطية من إعداداتك.

ملاحظة أمان: سكريبت المستودع يحتوي على تعليق لأمر تثبيت يستخدم --no-check-certificate، لكن الأمر الذي أرسلته هنا لا يستخدم هذا الخيار. لم أشغّل السكريبت على جهاز فعلي.
