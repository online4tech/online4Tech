ArabicSavior — المنقذ لاستعادة اللغة العربية

إصلاح عرض الخطوط العربية وإتاحة تغيير نوع الخط في واجهة الرسيفر.

📌 وظيفة البلجن

حسب وصف المستودع الرسمي، ArabicSavior من تطوير mfaraj57 وRAED، ومهمته إصلاح الخطوط العربية وإمكانية تغيير نوع الخط. ممكن يفيد لو الحروف العربية بتظهر بشكل غير صحيح في واجهة Enigma2، لكن النتيجة بتعتمد على صورة النظام والخطوط المثبتة.

المستودع الرسمي على GitHub ↗ · README الرسمي ↗

⭐ معلومات ومميزات مؤكدة

  • إصلاح مشاكل الخطوط العربية في واجهة Enigma2.
  • تغيير نوع الخط المستخدم، حسب ما يدعمه إصدار البلجن وصورة النظام.
  • سكريبت التثبيت بالمستودع يحدد الإصدار 2.5 في النسخة التي تمت مراجعتها.
  • سكريبت التثبيت يحاول حفظ نسخة من keymap.xml واستعادتها، ثم يعيد تشغيل واجهة Enigma2 بعد التثبيت.

مهم: إعادة تشغيل واجهة Enigma2 مذكورة صراحة في السكريبت. احفظ أي إعدادات أو عمل قبل التثبيت، ولا تفصل الجهاز أثناء التنفيذ.

🖼️ صور البلجن

لم أجد في README الرسمي لقطات شاشة مؤكدة لواجهة ArabicSavior، لذلك لم أضف صورًا تخمينية. يمكن إضافة صور حقيقية عند توفرها من واجهة البلجن نفسها.

تصفح ملفات المشروع على GitHub ↗

⌨️ أوامر التثبيت عبر Telnet / SSH

الأوامر كما أرسلتها، بالترتيب:

opkg update opkg install wget wget https://raw.githubusercontent.com/fairbird/ArabicSavior/main/installer.sh -O - | /bin/sh

مراجعة سكريبت التثبيت قبل التشغيل ↗

🛠️ خطوات التثبيت وملاحظات التوافق

  1. اتصل بالرسيفر من خلال Telnet أو SSH.
  2. تأكد أن جهازك يستخدم صورة تدعم مدير الحزم opkg؛ بعض الصور الأخرى تستخدم آلية مختلفة.
  3. راجع سكريبت التثبيت من الرابط الرسمي قبل تشغيله، لأنه ينزّل ملفات ويغيّر ملفات البلجن على الجهاز.
  4. نفّذ الأوامر بعد التأكد من توافق البلجن مع موديلك وصورة النظام.
  5. انتظر انتهاء العملية وإعادة تشغيل واجهة Enigma2، ثم افتح قائمة البلجن وابحث عن ArabicSavior.

التوافق مع كل موديلات الرسيفر وصور النظام غير مضمون من المعلومات المتاحة وحدها. لم يتم اختبار التثبيت على جهاز فعلي هنا.
