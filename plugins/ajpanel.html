AJPanel

إدارة الملفات والقنوات وIPTV والشبكة والنسخ الاحتياطي وأدوات متعددة من داخل الرسيفر.

📌 نبذة عن البلجن

حسب README الرسمي لمستودع المطوّر AMA Jamry، فإن AJPanel إضافة لأجهزة الاستقبال العاملة بنظام Enigma2. الإصدار الظاهر في README هو v10.8.6.

⭐ المميزات المذكورة رسميًا

  • إدارة الملفات، ومدير FTP.
  • أدوات IPTV وتصفح الأفلام.
  • أدوات الخدمات والقنوات ومحرر Bouquet.
  • إدارة Picons وأدوات EPG.
  • محاكي طرفية Terminal Emulator.
  • أدوات SoftCam وإدارة البلجنات.
  • النسخ الاحتياطي والاستعادة.
  • إعدادات التاريخ والوقت والشبكة.
  • مراقبة الإشارة Signal Monitor.
  • قائمة مخصصة، ومدير تنزيلات، وقوائم سياقية للبحث وتصفح القنوات.

الصورة التالية مرفقة في README الرسمي. كما يوفّر المستودع صور شرح إضافية للأدوات والواجهات.

⌨️ أوامر التثبيت عبر Telnet / SSH

1) رابط التثبيت من مستودع المطوّر

wget --no-check-certificate https://raw.githubusercontent.com/AMAJamry/AJPanel/main/installer.sh -O - | /bin/sh

2) رابط التثبيت من المستودع الذي أرسلته

wget https://raw.githubusercontent.com/biko-73/AjPanel/main/installer.sh -O - | /bin/sh

تم الحفاظ على الأمرين كما أرسلتهما. لم أتمكن من التحقق بشكل مستقل من أن نسخة biko-73 مطابقة تمامًا لنسخة المطوّر أو من حالة تحديثها.

⚠️ ملاحظات قبل التثبيت

  • راجع سكريبت التثبيت قبل تشغيله؛ فهو ينزّل كودًا من الإنترنت وينفذه مباشرة على الرسيفر.
  • الأمر الأول يستخدم --no-check-certificate، ما يعطّل التحقق من شهادة HTTPS ويقلل الحماية من الاتصال غير الموثوق.
  • يوضح README طرق تثبيت ملفات IPK أو DEB يدويًا، كما يشرح التحديث من داخل AJPanel.
  • خذ نسخة احتياطية من الإعدادات المهمة قبل التثبيت، وتأكد من توافق الحزمة مع صورة Enigma2 لديك.

لم يتم تشغيل أو اختبار أي سكريبت على جهاز فعلي. المعلومات الوظيفية أعلاه مأخوذة من README الرسمي، أما تطابق المستودع الثاني فلم يتم تأكيده.
