🎧 بلجن صوتيات لـ Enigma2

IPAudio Pro — مشغل الصوتيات والبث

قوائم تشغيل متعددة، تحكم في الصوت، وإدارة من واجهة ويب.

📌 وظيفة البلجن

بحسب README وسكريبت التثبيت في مستودع popking159/ipaudio، IPAudio بلجن لبث وتشغيل الصوتيات على Enigma2، مع تنظيم المحطات وقوائم التشغيل حسب الفئات، بما فيها الموسيقى والقرآن والرياضة.

المستودع على GitHub ↗ · README والمميزات ↗ · إصدارات البلجن ↗

⭐ المميزات حسب المستودع

  • قوائم تشغيل مقسمة لفئات، مع إضافة وتعديل وحذف القنوات وإعادة ترتيبها بالسحب والإفلات من واجهة الويب.
  • واجهة ويب على العنوان المحلي http://عنوان-الرسيفر:8080/ipaudio.
  • التحكم في تأخير الصوت بخطوات 0.5 ثانية، وتأخير TimeShift لمزامنة الصوت مع البث التلفزيوني.
  • دعم GStreamer وFFmpeg، والتحكم في مستوى صوت البث الخارجي.
  • دعم صور القنوات (Picons)، وقائمة شبكية، ومراقبة حالة الشبكة وروابط بث متعددة الصيغ.
  • ثيمات لونية متعددة، حسب وصف README.

الإصدار الموجود في سكريبت التثبيت الذي تمت مراجعته هو 8.11؛ وقد يتغير مع تحديث المستودع.

🖼️ صور حقيقية من مستودع المشروع

الصور التالية مرتبطة مباشرة بصور مرفوعة في مستودع GitHub.

⌨️ أمر التثبيت عبر Telnet / SSH

الأمر كما أرسلته:

wget -q --no-check-certificate https://raw.githubusercontent.com/popking159/ipaudio/main/installer-ipaudio.sh -O - | bash

🛠️ ملاحظات قبل التثبيت

  • السكريبت الذي تمت مراجعته ينزّل حزمة IPK من صفحة إصدارات GitHub ويثبتها باستخدام opkg.
  • لو كان إصدار سابق من IPAudio مثبتًا، يحاول السكريبت إزالته وعمل نسخة احتياطية من قوائم التشغيل JSON الموجودة في /etc/enigma2/ipaudio.
  • بعد نجاح التثبيت، يعيد تشغيل واجهة Enigma2؛ احفظ عملك قبل البدء.
  • واجهة الويب المذكورة في README تستخدم المنفذ 8080 والمسار /ipaudio؛ قد تحتاج للوصول من جهاز على نفس الشبكة.

تنبيه أمني: الأمر يستخدم --no-check-certificate، ما يعطّل التحقق من شهادة HTTPS أثناء تنزيل السكريبت. الأفضل مراجعة السكريبت والتأكد من مصدره قبل التنفيذ. التوافق يعتمد على صورة Enigma2 وموديل الجهاز، ولم يتم اختبار التثبيت على رسيفر فعلي هنا.
