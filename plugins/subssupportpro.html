📌 وظيفة البلجن

SubsSupportPro هو إصدار مطوّر من SubsSupport لأجهزة Enigma2، مخصص للبحث عن ملفات الترجمة واختيارها ومزامنتها مع الفيديو. وتوضح مراجع المشروع المنشورة أنه يضم مزوّدين للبحث، منهم مزوّدون يحتاجون API key وآخرون مجانيون، مع شعارات للمزوّدين وواجهة محسّنة.

موضوع SubsSupportPro ومعلومات الإصدار ↗ · شرح SubsSupport في دليل OpenATV ↗

⭐ أبرز المميزات المذكورة في المصادر

  • البحث عن الترجمات عبر مزوّدين مختلفين، مع اختيار الترجمة المناسبة.
  • ضبط تزامن الترجمة مع الصوت والصورة، بما في ذلك خيارات تعديل التوقيت.
  • مزوّدون يتطلبون API key، ومزوّدون آخرون متاحون بدون مفتاح بحسب إعداد الخدمة.
  • شعارات للمزوّدين، وأعلام دول، وثيمات لونية متعددة.
  • أداة ترجمة للواجهة، وعرض حالة التحديث على الشاشة الرئيسية.
  • تذكر مراجع الإصدار دعم Python 2 وPython 3 على صور Enigma2 مفتوحة المصدر؛ التوافق الفعلي يعتمد على الإصدار والصورة.

قد تختلف قائمة المزوّدين والميزات حسب إصدار البلجن، وقد تتطلب بعض الخدمات إعداد حساب أو مفتاح API خاص بها.

🖼️ صور الواجهة

تعرض المناقشة المرتبطة بالمشروع مرفقات وصورًا للواجهة، لكن لم أتمكن من الحصول على روابط صور مباشرة يمكن تضمينها بثقة في هذه الصفحة. بدلًا من عرض صور غير مؤكدة، استخدم رابط الموضوع للاطلاع على الصور المرفقة.

⌨️ أمر التثبيت عبر Telnet / SSH

الأمر كما أرسلته:

wget -q "--no-check-certificate" https://github.com/popking159/SubsSupportPro/raw/main/subssupportpro-install.sh -O - | /bin/sh

محاولة فتح سكريبت التثبيت للمراجعة ↗

🛠️ ملاحظات قبل التثبيت

  1. تأكد من توافق إصدار البلجن مع صورة Enigma2 وموديل الرسيفر.
  2. راجع سكريبت التثبيت قبل تشغيله، لأنه ينزّل كودًا من الإنترنت وينفذه على الجهاز.
  3. قد تحتاج بعض مزوّدات الترجمة إلى API key؛ راجع تعليمات المزوّد نفسه ولا تشارك مفاتيحك مع الآخرين.
  4. بعد التثبيت، افتح إعدادات البلجن واضبط اللغات والمزوّدين والتزامن حسب حاجتك.

تنبيه: الأمر يحتوي على --no-check-certificate، ما يعطّل التحقق من شهادة HTTPS عند التنزيل. لم يتم اختبار التثبيت على جهاز فعلي، كما تعذّر الوصول إلى ملفات المستودع مباشرة أثناء إعداد هذه الصفحة؛ لذلك اعتمد شرح الوظائف على مراجع منشورة خارج المستودع، وقد تختلف التفاصيل بين الإصدارات.
