صندوق الأدوات

ملاحظة: الأوامر المعروضة لا يتم تشغيلها من المتصفح. راجع الأمر، واتصل بجهازك عبر SSH من أداة موثوقة قبل التنفيذ.

# املأ الحقول واضغط «معاينة الإعداد»

المعاينة لا تحفظ كلمة السر داخل الموقع ولا تتصل بأي سيرفر؛ ستظهر كلمة السر في النص الناتج، فاحتفظ به محليًا ولا تشاركه. لا تستخدمها للوصول غير المصرح به إلى خدمات أو قنوات مدفوعة.

استخدم فقط قوائم ومصادر IPTV المصرّح لك بمشاهدتها. لا تدخل كلمات سر حساسة في صفحة عامة.

05 / SERVER FILES

إنشاء ملفات السيرفرات

جهّز ملفات محلية بأسماء ثابتة، وبعدها راجعها قبل نقلها للرسيفر. كلمات السر لا تُحفظ داخل الموقع.

ℹ️
معلومة مهمة مفيش مسار IPTV واحد لكل صور وبلجنات Enigma2. الملف هنا بيتسمّى playlist بدون امتداد، ومسار استخدامه بيتحدد حسب البلجن اللي بيقرأ قوائم M3U. قوائم القنوات التقليدية بتستخدم ملفات bouquet داخل /etc/enigma2/ بصيغة مختلفة.
اكتب رابطًا مصرحًا لك باستخدامه. لو أدخلت محتوى يدويًا، هيتقدم على الرابط.

الملف الناتج فيه بيانات الاتصال الحساسة؛ احتفظ به محليًا ولا ترفعه على GitHub أو تشاركه مع أي شخص.

استخدم نفس بيانات السيرفر أو اكتب بيانات مستقلة. الملف الناتج اسمه ncam.server.

06 / LOCAL BRIDGE

ربط مباشر بالرسيفر

أداة الربط المحلية جاهزة للاتصال من نفس الكمبيوتر بعد تشغيل start.bat. تقدر تفحص الجهاز وتنشئ نسخة احتياطية وتنزّلها؛ نقل ملفات الإعدادات للرسيفر يحتاج مراجعة المسار والتوافق قبل أي استبدال.

🔐 اتصال SSH محلي

الخدمة المحلية المطلوبة تعمل على الكمبيوتر نفسه، وتستقبل المهام المحددة فقط.

تجهيز الربط
عنوان IP والمنفذ واسم المستخدم بيتحفظوا تلقائيًا في المتصفح؛ كلمة المرور اختيارية.
بانتظار تشغيل أداة الربط المحلية…

لا تستخدم Telnet لإرسال كلمات مرور. المتاح حاليًا: معلومات النظام، مساحة التخزين، فحص الخدمات، إنشاء النسخة الاحتياطية وتنزيلها للكمبيوتر. لا ترفع ملفات إعداد تحتوي بيانات دخول إلا بعد مراجعتها محليًا والتأكد من مسار الجهاز وصيغة إصدار OSCam/NCam.
