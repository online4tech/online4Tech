# Online4Tech Bridge (Windows)

جسر محلي بيربط صفحات Online4Tech بالرسيفر على نفس الشبكة. من الإصدار 2.0 بيدعم **التثبيت التلقائي** من صفحة مركز البلجنات.

## التثبيت التلقائي (الطريقة الموصى بها)
1. افتح مركز البلجنات واختار أي بلجن/سكين/قائمة قنوات، واضغط «التثبيت التلقائي».
2. أول مرة بس: نزّل `O4T-Bridge.exe` من النافذة وشغّله مرة واحدة (لو ويندوز ظهّر تحذير: More info ثم Run anyway). مش محتاج صلاحيات Administrator ولا Python.
3. البرنامج بيسجّل نفسه في حساب المستخدم (مجلد `%LOCALAPPDATA%\Online4Tech\Bridge`)، ويشتغل في الخلفية، ويفتح تلقائي مع الويندوز.
4. الصفحة بتكمل لوحدها: اكتب IP الرسيفر وكلمة المرور واضغط «ابدأ التثبيت».
5. لو المتصفح سأل عن السماح بالاتصال بالشبكة المحلية، اضغط «سماح».

للإلغاء: شغّل `O4T-Bridge.exe --uninstall`.

### إزاي بيشتغل التثبيت
- الصفحة بتبعت **رقم العنصر** فقط، مش أوامر. الجسر بيجيب بيانات العنصر من قائمة الموقع (`assets/allblugin/demo-data.json`).
- الجسر بيحمّل الملف على الكمبيوتر من مصادر GitHub المعتمدة فقط (حسابات `online4tech` و`emilnabil`)، ويفحصه، ويرفعه للرسيفر عبر SSH، وبعدين يثبّته:
  - `.ipk` ← `opkg install`
  - `.tar.gz` ← يتفحص الأول (مسارات داخل مجلدات Enigma2 بس، بدون روابط أو ملفات خاصة) ثم يتفك على الرسيفر
  - `.sh` ← سكريبت نصي يتشغّل على الرسيفر
- بيكتشف تلقائي صورة الرسيفر ونسخة Python ومساحة `/tmp` قبل التثبيت.
- لو عنصر في الكتالوج فيه حقل `sha256`، الجسر بيرفض أي ملف مش مطابق له.
- بعد التثبيت بيعيد تشغيل واجهة الرسيفر (اختياري من النافذة).
- **غير مدعوم عمدًا:** خدمات فك التشفير ومشاركة الكروت (CCcam وOScam وNCam وما شابهها) والنسخ الاحتياطية الكاملة للصور.

### بصمة SSH
أول اتصال بأي رسيفر بيسجّل بصمته في `known_hosts` جوه مجلد الجسر، وبعد كده بيتأكد منها. لو اتغيرت (بعد إعادة تثبيت الصورة مثلًا) النافذة بتعرض زر «نسيان البصمة القديمة وإعادة المحاولة».

## التشغيل اليدوي بـ Python (للمطورين)
## المتطلبات
- Windows 10 أو 11.
- Python 3 من https://www.python.org/downloads/windows/ (فعّل Add Python to PATH أثناء التثبيت).
- تفعيل SSH على الرسيفر، ومعرفة عنوان IP واسم المستخدم وكلمة المرور.
- الكمبيوتر والرسيفر على الشبكة المحلية نفسها.

## التشغيل
1. نزّل الملفات الثلاثة من هذا المجلد إلى مجلد واحد على الكمبيوتر: bridge.py و start.bat و README.md.
2. شغّل start.bat. أول مرة سيُثبّت Paramiko المجاني، وقد يحتاج اتصال إنترنت للتثبيت.
3. اترك نافذة البرنامج مفتوحة أثناء الاستخدام.
4. افتح https://online4tech.github.io/online4Tech/enigma2-manager.html واضغط «فحص الأداة المحلية».
5. اكتب IP الرسيفر، والمنفذ 22 عادةً، واسم المستخدم وكلمة مرور SSH.
6. لو ظهرت رسالة عن بصمة SSH، افتح PowerShell واكتب ssh root@192.168.1.120 مع استبدال العنوان بعنوان رسيفرك. راجع بصمة المفتاح على شاشة الرسيفر إن أمكن، ولا توافق إلا لو واثق أن الاتصال بالرسيفر الصحيح. بعد تسجيل المفتاح أعد المحاولة.

## الأمان
- الخدمة مربوطة على 127.0.0.1 فقط ولا تستقبل اتصالات من أجهزة أخرى.
- تقبل الصفحة الرسمية فقط، وتسمح بعناوين IP خاصة للشبكة المحلية.
- كلمة المرور لا تُحفظ في ملفات الأداة. لا تفعّل حفظ كلمة المرور في المتصفح.
- جلسة SSH تبقى في الذاكرة وتنتهي بعد 10 دقائق من عدم النشاط، أو عند إغلاق نافذة الأداة.
- لا تستخدمها إلا مع جهاز تملكه أو لديك تصريح بإدارته.
- الوظائف الحالية قراءة معلومات النظام، فحص التخزين والخدمات، وإنشاء نسخة احتياطية محلية. أُضيف كونسول تشخيص يسمح فقط بقائمة أوامر قراءة محددة (مثل uname -a وdf -h وfree -h وip addr وopkg list-installed وps وuptime). لا ينفذ أوامر Shell عشوائية ولا يثبت/يحذف بلجنات ولا يستبدل ملفات الإعدادات تلقائيًا.

## ملاحظات
إذا كان SSH على الرسيفر معطّلًا، فعّله من إعدادات الصورة أولًا. لا تفتح منفذ SSH على الإنترنت. إذا فشل الاتصال، تأكد من عنوان IP والمنفذ وكلمة المرور، وأن جدار الحماية لم يمنع Python.


## رفع ملف IPTV إلى الرسيفر
1. شغّل start.bat وافتح صفحة Enigma2 Manager.
2. أدخل IP الرسيفر وبيانات SSH، ثم اختار ملف .m3u أو .m3u8 من قسم «إرسال ملف IPTV».
3. أكد أن لديك تصريحًا باستخدام القائمة واضغط رفع الملف.
4. يتحقق الوسيط من صيغة M3U والحجم، ويرفعه عبر SFTP إلى /etc/enigma2/ مباشرةً (وهو مجلد إعدادات Enigma2 القياسي) ثم يتحقق من الحجم على الرسيفر.

الرفع لا ينشئ Bouquet ولا يفعّل قنوات تلقائيًا؛ يلزم استيراد القائمة من بلجن متوافق. الحد الأقصى 5 ميجابايت. أوامر التشخيص تظل مقيدة بقائمة القراءة فقط.

## تثبيت أوامر مركز التحكم (Chanal-List)
صفحة `Chanal-List/enigma2-control-center.html` تستخدم نفس الجسر ونفس المنفذ (نفس الـ Origin: `https://online4tech.github.io`).
- الصفحة تبعت `source: "center"` ورقم السجل واسمه فقط. الجسر نفسه يقرأ الأمر من `Chanal-List/data/enigma2/commands.json`، ولو الاسم مش مطابق للسجل يرفض.
- الشكل الوحيد المقبول: `wget [خيارات] <https-url> -O - | sh` (أو `/bin/sh` / `bash`). أي `;` أو `&&` أو `$` أو رابط http أو خيار تاني يتم رفضه.
- قائمة `commands.json` على موقعك هي مصدر الثقة، فالجسر بيقبل أي رابط `http/https` فيها، بشرط يكون اسم موقع عادي (مش عنوان IP ولا localhost ولا شبكة محلية، ولا منفذ غير 80/443، ولا بيانات دخول في الرابط). الجسر يحمّل السكربت بنفسه، يفحصه كنص (حد أقصى 512KB)، يرفعه للرسيفر ويشغّله بـ `sh` — مش بينفّذ `wget | sh` على الرسيفر. روابط http غير مشفّرة وبتظهر في الصفحة بتحذير.
- أوامر الحذف (`rm ...`) وتصنيفات softcam/مشاركة الكروت مرفوضة. الباقي يفضل «نسخ الأمر» في الصفحة.
