# Online4Tech Downloads — قالب GitHub Pages

## محتويات القالب
- `index.html`: الصفحة الرئيسية، فيها بحث وفلاتر للأقسام.
- `downloads/README.txt`: مكان توضيحي لتنظيم ملفات التحميل.
- `guides/README.txt`: مكان توضيحي لتنظيم الشروحات.

## النشر للمبتدئين
1. سجّل الدخول إلى GitHub وافتح https://github.com/new
2. أنشئ مستودعًا باسم `online4tech-downloads` واجعله Public.
3. ارفع `index.html` والمجلدين `downloads` و`guides` إلى جذر المستودع.
4. افتح Settings ثم Pages.
5. في Build and deployment اختر Deploy from a branch.
6. اختر `main` والمجلد `/(root)` ثم Save.
7. رابط الموقع يكون: `https://YOUR-USERNAME.github.io/online4tech-downloads/`

## مهم قبل النشر
- ابحث داخل `index.html` عن عبارة `رابط تجريبي — استبدله` واستبدل روابطها بروابط الملفات الحقيقية.
- البطاقات الحالية أمثلة فقط وليست ملفات فعلية.
- لا تضع كلمات مرور أو بيانات خاصة في المستودع العام.
- GitHub Pages موقع ثابت؛ لا يحتوي على لوحة تحكم لإدارة الملفات. لإضافة ملف جديد، ارفع الملف إلى GitHub ثم عدّل البطاقة والرابط.
- للملفات الكبيرة، استخدم استضافة ملفات موثوقة واربطها من الصفحة بدل وضعها داخل المستودع.
- ارفع فقط الملفات التي تملك حق توزيعها.
