# Online4Tech daily EPG generator

## The problem
The EPG sources in Khaled's pack mostly point at dead links (17 of 42
URLs return 404 — iptv-org stopped hosting ready-made guides, bevy /
jawwytv / epgshare are gone). A pack built on dead links imports almost
nothing for Nilesat.

## The fix — our own sources, under our name, updated daily
A GitHub Actions workflow in `online4tech/online4Tech`
(`.github/workflows/epg-daily-update.yml`) runs every day at 03:00 UTC
(05:00 EET) and:

1. Clones the public iptv-org/epg grabber (Unlicense, updated daily by
   its maintainers) and installs it.
2. Grabs fresh 7-day guides for **bein.com (71 channels), osn.com (80),
   elcinema.com (104), beinsports.com (78)** — all four sites are
   green/working in the grabber's status list, verified 2026-11-27.
   beinsports.com was added because beIN Sports 1 is only provided by
   it (not by bein.com/osn.com/elcinema.com).
3. Remaps the channel ids in the generated guides to the Online4Tech
   ids from our channels files (`epg/scripts/remap-epg-ids.py` +
   `epg/scripts/id-mapping.json` — the mapping is built after the
   full-coverage pack rebuild, from the pack + the iptv-org channels
   database).
4. Commits the fresh guides into `epg/guides/` in our repo.

The plugin's EPG sources then point at **our own raw GitHub URLs**, e.g.
`https://raw.githubusercontent.com/online4tech/online4Tech/main/epg/guides/bein.com.xml`
— links that never die because we regenerate the files behind them daily.

## Files
- `epg-daily-update.yml` — the workflow (must be created via the cloud
  browser; the GitHub connector cannot push `.github/workflows/`).
- `remap-epg-ids.py` — id remapper (guide XML in, our ids out).
- `id-mapping.json` — iptv-org id -> Online4Tech xmltv id (TO BUILD
  after the pack rebuild).

## What v1 covers / what it doesn't
- v1: beIN + OSN + elCinema (Arabic + English where the sites provide
  them). Small files, fast grab, the Nilesat core.
- NOT in v1: MBC and the Egypt/Saudi/UAE/Qatar country packs — their
  original data came from local files that are not in the tarball, and
  no iptv-org grabber site was verified for them yet. Phase 2: find a
  working grabber site (or another public source) for MBC + the country
  packs, then add it to the workflow's `--sites` list.
- The Rytec/Igor sources stay in the pack as-is (they are separate
  public sources, not generated by us).

## Failure handling
- If one site fails on a run, the workflow still commits the guides
  that succeeded (the grabber exits per-site; a failed site leaves its
  previous day's file in place — never an empty guide).
- If the whole run fails, the previous day's guides stay live. Nothing
  breaks on the receiver; the EPG just stays one day older.
- The workflow runs on GitHub's servers, never on Liam's connection
  (metered internet rule).

## Publishing the pack to GitHub
The rebuilt pack's sources/channels XMLs go to `epg/` in
`online4tech/online4Tech` (via the GitHub connector — non-workflow
files push fine). The plugin installs them from the plugin folder
(bundled) and downloads channel files from `epg/` raw URLs.
