# Online4Tech Skins

قسم اسكينات Enigma2.

## الاسكين المتاح
| الاسم | الملف | المصدر |
|---|---|---|
| LiteHD 1.6 | [skins-litehd_1.6_all.ipk](ipk/skins-litehd_1.6_all.ipk) | [المستودع الأصلي](https://github.com/emilnabil/skins-openatv) |

## التثبيت عبر Telnet
من داخل مجلد الاسكينات على الجهاز، يمكن استخدام سكريبت التثبيت:
```sh
wget -O - https://raw.githubusercontent.com/online4tech/online4Tech/main/downloads/online4tech/skins/installers/install-litehd.sh | sh
```

**ملاحظات:** الحزمة من مصدر OpenATV الأصلي بعد إذن مالكه. لم يتم فك الحزمة الثنائية وفحص محتوياتها الداخلية أو اختبارها على جهاز فعلي؛ تحقق من توافق صورة جهازك قبل التثبيت.
