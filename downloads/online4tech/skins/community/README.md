## التثبيت

- ملفات `.ipk`: ارفع الملف إلى جهاز Enigma2 ثم استخدم `opkg install /tmp/اسم-الملف.ipk` عبر Telnet/SSH، أو استخدم سكربت التثبيت المرفق إن كان مناسبًا لنوع الصورة.
- ملفات `.deb`: استخدم مدير الحزم المتوافق مع صورة الجهاز؛ راجع سكربت المصدر أو وثائق الصورة لتحديد `dpkg` أو `apt`.
- ملفات `.tar.gz`: بعض الملفات أرشيفات إضافات وليست حزمًا جاهزة؛ راجع سكربت التثبيت المرفق قبل فكها أو تثبيتها.
- بعض السكربتات تستخدم روابط المصدر الأصلي لتنزيل الحزمة وقت التثبيت. الفهرس يسجل أوامر التثبيت المباشرة التي وجدها، عند توفرها.

لم يتم تشغيل أو تدقيق سكربتات المصدر. راجع محتوى السكربت وتوافق المعمارية وإصدار Python وصورة الجهاز قبل التنفيذ. بعض الأوامر المصدرية تنزّل سكربتًا من الإنترنت وتشغّله مباشرة؛ لا تستخدمها قبل مراجعة محتواها.

تم تجنب استبدال أي ملف موجود. واستُبعدت عناصر تشير أسماؤها أو مساراتها إلى softcam وIPTV ومفاتيح/قارئات السيرفرات وأدوات كلمات المرور والمحاكيات.
