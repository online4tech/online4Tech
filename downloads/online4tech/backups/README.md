# Online4Tech Backups

مكتبة النسخ الاحتياطية وصور الأنظمة الخاصة بأجهزة Enigma2.

## التحميل

تم نقل **65 ملف باك أب** إلى GitHub Releases داخل مستودع Online4Tech، موزعة على موديلات Vu+ وNovaler. روابط التحميل المعروضة في صفحات الأجهزة بالموقع تشير مباشرة إلى ملفات Releases في هذا المستودع.

- [افتح مكتبة الباك أب على الموقع](https://online4tech.github.io/online4Tech/backups/index.html)
- [استعرض جميع Releases الخاصة بالباك أب](https://github.com/online4tech/online4Tech/releases)

## ملاحظات

- روابط التحميل المباشر تستخدم ملفات GitHub Releases التابعة لمستودع Online4Tech.
- تم الإبقاء على روابط المصدر الأصلية داخل بيانات الفهرس كمرجع للمصدر، ولم يتم حذف أي شيء من المستودعات الأصلية.
- قبل الاستعادة، تأكد من تطابق موديل الجهاز وصورة النظام، واحتفظ بنسخة من إعداداتك الحالية.
- ملف RX-Launcher APK محفوظ في Release منفصل ولا يُعرض ضمن نسخ Enigma2 الاحتياطية.
