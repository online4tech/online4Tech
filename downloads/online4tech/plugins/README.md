# Online4Tech Plugins

قسم إضافات Enigma2.

## الحزم المنقولة
| الإضافة | الملف | التثبيت |
|---|---|---|
| Dreambox NTP Sync | [IPK](ipk/dreambox-ntp-sync_all.ipk) | [Telnet installer](installers/install-dreambox-ntp-sync.sh) |

**ملاحظات التوافق والسلامة**
- الملفات من المصدر الأصلي بعد إذن مالكه.
- لم يتم فك الحزمة الثنائية وفحص كل ملفاتها الداخلية في هذه المرحلة؛ لذلك لا تعتبر الحزمة معتمدة أو مختبرة على جهاز فعلي.
- سكريبت التثبيت المحلي لا ينفذ إعادة تشغيل تلقائية، بخلاف سكريبت المصدر.
- راجع توافق صورة Enigma2 قبل التثبيت.
