# Online4Tech Plugins

قسم إضافات Enigma2 المنقولة إلى مستودع Online4Tech.

## طريقة التنظيم
- `ipk/`: حزم IPK.
- `installers/`: سكريبتات تثبيت Telnet الخاصة بالحزم الموجودة هنا.

## الحزمة المتاحة
| الإضافة | الملف | طريقة التثبيت |
|---|---|---|
| Dreambox NTP Sync | [dreambox-ntp-sync_all.ipk](ipk/dreambox-ntp-sync_all.ipk) | [سكريبت التثبيت](installers/install-dreambox-ntp-sync.sh) |

**ملاحظة:** الحزمة من المصدر الأصلي بعد إذن مالكه. تم تعديل طريقة التثبيت لتجنب إعادة تشغيل الجهاز تلقائيًا. لم يتم تشغيل الحزمة على جهاز فعلي؛ راجع توافق صورة Enigma2 قبل التثبيت.
